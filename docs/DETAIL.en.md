Get next-step suggestions, save closing notes, switch Agent presets, hear session alerts,
and view session title history.
Click the rewind icon beside Copy on a user message to return it to the composer.
Click the translate icon under any message to translate it with Google Translate.
While the session is busy, the Send icon shows when clicking it would queue the message.
New sessions can be automatically pinned in the sidebar when you send the first message.
Each feature has its own switch.

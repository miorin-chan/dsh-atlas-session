# План модульного улучшения сеансов

Получайте подсказки о следующих шагах, сохраняйте итоговые заметки, меняйте предустановки агента,
включайте звуковые оповещения и просматривайте историю заголовков сеансов.
Нажмите значок отката слева от кнопки копирования под сообщением пользователя, чтобы вернуть его в поле ввода.
Нажмите значок перевода под любым сообщением, чтобы перевести его с помощью Google Переводчика.
Пока сеанс занят, значок отправки показывает, будет ли сообщение поставлено в очередь при нажатии.
Новые сеансы можно автоматически закреплять на боковой панели.
Каждую функцию можно включать и выключать отдельно.

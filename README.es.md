# Plan de mejora modular para sesiones

Recibe sugerencias sobre los próximos pasos, guarda notas de cierre, cambia los ajustes preestablecidos del agente,
recibe avisos sonoros y consulta el historial de títulos de las sesiones.
Pulsa el icono de rebobinar junto a Copiar en un mensaje del usuario para devolverlo al cuadro de entrada.
Pulsa el icono de traducción bajo cualquier mensaje para traducirlo con Google Traductor.
Mientras la sesión está ocupada, el icono de Enviar indica si al pulsarlo el mensaje se pondrá en cola.
Las sesiones nuevas pueden aparecer automáticamente al principio de la lista de sesiones fijadas.
Puedes activar o desactivar cada función por separado.

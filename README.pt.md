# Plano de melhoria modular para sessões

Receba sugestões de próximos passos, salve notas de encerramento, alterne entre predefinições do agente,
ouça alertas e consulte o histórico de títulos das sessões.
Clique no ícone de retroceder ao lado de Copiar em uma mensagem do usuário para devolvê-la ao campo de entrada.
Clique no ícone de tradução abaixo de uma mensagem para traduzi-la com o Google Tradutor.
Enquanto a sessão está ocupada, o ícone Enviar indica se o clique colocará a mensagem na fila.
Você pode ativar ou desativar cada função separadamente.

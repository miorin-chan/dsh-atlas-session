# Modularer Verbesserungsplan für Sitzungen

Holen Sie sich Vorschläge für nächste Schritte, speichern Sie Abschlussnotizen, wechseln Sie Agent-Voreinstellungen,
hören Sie Sitzungssignale und sehen Sie den Verlauf der Sitzungstitel ein.
Mit dem Rückgängig-Pfeil unter einer ausstehenden Nachricht kannst du sie zurückziehen.
Jede Funktion lässt sich separat ein- und ausschalten.
